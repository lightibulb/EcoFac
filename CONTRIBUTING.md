# Contributing to EcoFac

## Development Rules
1. Work only within the approved EcoFac repository.
2. Never commit real facility data. Use synthetic data exclusively.
3. Ensure all tests pass (`pytest`) and code is strictly linted (`ruff check`).
4. Do not add paid AI dependencies or complex infrastructure (Postgres, Docker) unless justified.
5. Update documentation when modifying behavior.

## Pull Request Process
1. Ensure the CI pipeline is green.
2. Update the README.md or relevant docs with details of changes.
3. The PR must be reviewed and approved by a maintainer.
