# EcoFac — Open Energy Intelligence for Facilities

**Tagline:** Open Energy Intelligence for Facilities

EcoFac is a reproducible, explainable, evidence-driven energy intelligence engine for facilities. It ingests synthetic meter data, assesses data quality, computes historical baselines, detects anomalies, attaches deterministic evidence, and tracks incidents through a defined lifecycle.

## ⚠️ Important Disclaimers
- **Synthetic Data Only:** EcoFac is not connected to any real building, meter, or BMS.
- **Not Production-Ready:** A successful test run or demonstration does not constitute production readiness.
- **No Authentication:** This is a local demonstration API. Do not expose it to untrusted networks.
- **No Equipment Control:** This system cannot and does not control physical equipment.

## Scope (Initial)
- Synthetic building and meter records
- CSV-based energy data ingestion
- Data normalization and quality assessment
- Historical energy baselines and anomaly detection
- Evidence-backed findings and incident tracking
- Before/after energy verification
- FastAPI REST API
- Reproducible automated evaluation

## Explicitly Out of Scope
- Real BMS integrations
- Real equipment control
- Automatic maintenance dispatch
- Work-order management
- Financial claims of verified savings
- Paid AI dependencies
- Complex digital twins

## Architecture
EcoFac is built with Python 3.11+, FastAPI, and SQLite. It follows a strict modular architecture:
- `src/ecofac/api`: FastAPI routes and Pydantic schemas.
- `src/ecofac/domain`: Core dataclasses.
- `src/ecofac/ingestion`: CSV parsing and normalization.
- `src/ecofac/quality`: Data quality assessment.
- `src/ecofac/detection`: Statistical anomaly detection.
- `src/ecofac/incidents`: Incident lifecycle and evidence.
- `simulator`: Synthetic data generation.
- `evaluation`: Metrics and verification engines.

## Setup Instructions
Requires Python 3.11+.
```bash
python -m pip install -e ".[dev]"
```

## Test Instructions
```bash
# Run linting
ruff check src tests simulator evaluation

# Run all tests
pytest tests/ -v

# Run the evaluation framework
python -m evaluation.runner
```

## API Documentation
Once the server is running (`uvicorn ecofac.main:app --reload`), visit `http://127.0.0.1:8000/docs` for the interactive OpenAPI documentation.

## Limitations
See [docs/limitations.md](docs/limitations.md) for a complete list. Key limitations include:
- SQLite is single-process.
- Statistical methods only (no deep learning).
- Anomalies are statistical, not confirmed operational faults.

# Security Policy

## Supported Versions
Currently, only the `main` branch is supported for security updates.

## Threat Model & Security Review
EcoFac is a local demonstration API handling synthetic data. It is **not** designed for public internet exposure without significant hardening.

### What we have implemented:
- **Input Validation:** All API inputs are validated via Pydantic.
- **File-Size Limits:** CSV uploads are restricted to 5MB to prevent memory exhaustion.
- **SQL Injection Protection:** All database queries use parameterized statements (`?` placeholders).
- **No Secrets:** The codebase requires no secrets, API keys, or credentials.
- **No Equipment Control:** The system has no write-access to physical systems.

### What is NOT implemented (Known Risks):
- **Authentication / Authorization:** There is no user login, no RBAC, and no tenant isolation.
- **Rate Limiting:** The API is susceptible to denial-of-service via request flooding.
- **Path Traversal:** File uploads are read into memory (not saved to disk), mitigating traditional path traversal, but large payloads are still a risk.
- **Audit Integrity:** Audit logs are append-only at the application layer, but a user with direct SQLite access could modify them.

## Reporting a Vulnerability
If you discover a security vulnerability, please do not open a public issue. Contact the repository maintainer directly.

# Architecture

EcoFac is a monolithic Python application designed for simplicity and auditability.

## Data Flow
1. **Ingestion:** Data is uploaded via CSV. The `pipeline.py` validates headers, normalizes units to kWh, converts timestamps to UTC, and writes to SQLite.
2. **Quality Assessment:** The `assessment.py` engine checks for missing, stale, duplicate, or invalid data. It outputs boolean flags and an `is_analysis_eligible` status.
3. **Detection:** The `anomaly.py` engine computes baselines (Rolling, MAD) and flags deviations. It generates an `Anomaly` record.
4. **Evidence & Incidents:** If an anomaly is found, the `lifecycle.py` manager creates an `Incident` and an `EvidenceRecord` containing the exact mathematical proof.
5. **Verification:** The `verification.py` engine compares pre/post consumption periods to validate interventions.

## Technology Stack
- **Language:** Python 3.11+
- **Web Framework:** FastAPI
- **Validation:** Pydantic v2
- **Database:** SQLite (via stdlib `sqlite3`)
- **Testing:** pytest
- **Linting:** Ruff

# Data Schema

The database is initialized via `src/ecofac/persistence/schema.sql`.

## Core Tables
- **organizations:** Represents the top-level entity.
- **buildings:** Physical structures belonging to an organization.
- **meters:** Measurement devices associated with a building.
- **energy_readings:** Normalized, time-series observations. Includes a `raw_value` column to preserve the original input.
- **data_quality_issues:** Logs of anomalies in the data itself (e.g., duplicates, invalid units).
- **anomalies:** Statistical deviations detected by the engine.
- **incidents:** Lifecycle tracking for anomalies.
- **evidence_records:** Immutable JSON proofs supporting an incident.
- **audit_events:** Append-only log of state changes.

## Integrity Rules
- All timestamps are stored in UTC ISO-8601 format.
- `UNIQUE(meter_id, timestamp_utc)` prevents duplicate readings.
- Missing readings are not filled; they are handled by the quality engine.

# Evaluation Methodology

EcoFac includes a reproducible evaluation framework (`evaluation/`) to measure accuracy.

## Synthetic Data

The `simulator/` generates 21,600 readings (5 buildings, 2 meters, 90 days) with:

- 40+ injected anomalies (spikes). Ground truth is reconciled AFTER the 1%
  missing-data drop, so every label is detectable in principle.
- Missing data scenarios (1% dropped).
- Duplicate data scenarios (1% duplicated).
- Stale data scenarios (3 days of halted updates).

The simulator also emits `quality_ground_truth.json` (injected defect counts)
so ingestion capture rates are measurable.

## Detection Metrics

- **Precision:** True Positives / (True Positives + False Positives)
- **Recall:** True Positives / (True Positives + True Negatives-free denominator)
- **F1 Score:** Harmonic mean of Precision and Recall.
- **PR-AUC:** Area under the Precision-Recall curve, computed by ranking all
  predicted anomalies by |z-score| (stored in `detection_parameters`) and
  sweeping the decision threshold (trapezoidal integration).
- **False Alerts / Bldg / Week:** Normalized noise metric.

## Verification Outcomes

Interventions are classified as SUCCESSFUL, FAILED, PARTIAL_IMPROVEMENT,
RECURRENCE, or INCONCLUSIVE. Baseline and post windows use canonical `Z`
timestamp bounds and exact day counts.

## Reproducibility Guardrails

- The runner refuses to publish (non-zero exit) if zero ground-truth
  anomalies are detected — silent blindness is structurally impossible.
- `tests/evaluation/test_runner_canary.py` plants known spikes and asserts
  the full analysis path finds them.
- Incidents are only created for anomalies whose data-quality window is
  eligible; ineligible findings are reported as gated.

# Known Limitations

1. **Synthetic Data Only:** EcoFac is not connected to real equipment.
2. **Not Production-Ready:** Does not include authentication, rate limiting, or horizontal scaling.
3. **SQLite Concurrency:** Single-process only. Concurrent writes will fail with "database is locked".
4. **Statistical Detection:** Detects mathematical deviations, not confirmed operational faults.
5. **No Weather Normalization:** The baseline does not account for outdoor temperature or occupancy.
6. **Evaluation Runner Performance:** The evaluation script runs detection on every single reading sequentially. This takes a few seconds for 21k readings but would be slow for millions.

# Threat Model

EcoFac is a local demonstration API. The primary assets are data integrity and reproducibility.

| STRIDE Category | Threat | Mitigation |
|---|---|---|
| **Spoofing** | Caller submits readings claiming a meter they don't own. | No auth in initial scope. Documented limitation. |
| **Tampering** | Modifying a CSV to hide an anomaly. | Evidence records reference immutable reading IDs. |
| **Repudiation** | User denies acknowledging an incident. | Incident transitions are timestamped and audited. |
| **Information Disclosure** | Synthetic data leaks. | All data is synthetically generated. |
| **Denial of Service** | Oversized CSV upload. | 5MB file size limit enforced at the API boundary. |
| **Elevation of Privilege** | Low-priv user closes incidents. | Out of scope initially (single-user model). |

**Non-Threat:** Because there is no physical control path and no BMS integration, the risk of commanding equipment is structurally eliminated.

# Copyright 2026 Lightibulb
"""Calculates anomaly detection and data quality metrics."""
import json
import sqlite3


def calculate_pr_auc(precisions: list[float], recalls: list[float]) -> float:
    """Calculate Area Under the Precision-Recall Curve (trapezoidal rule)."""
    if not precisions or not recalls:
        return 0.0
    sorted_pairs = sorted(zip(recalls, precisions, strict=True))
    auc = 0.0
    prev_recall = 0.0
    prev_precision = 1.0
    for r, p in sorted_pairs:
        width = r - prev_recall
        height = (p + prev_precision) / 2.0
        auc += width * height
        prev_recall = r
        prev_precision = p
    return auc


def _ranked_pr_curve(
    predictions: list[sqlite3.Row], truth_set: set[tuple[str, str]]
) -> float:
    """Build a real PR curve by sweeping a decision threshold over |z|.

    Each anomaly stores its z-score in detection_parameters; ranking by
    |z-score| and walking the cutoff yields (precision, recall) operating
    points, which are integrated into PR-AUC.
    """
    if not truth_set or not predictions:
        return 0.0
    best: dict[tuple[str, str], float] = {}
    for p in predictions:
        try:
            params = json.loads(p["detection_parameters"] or "{}")
            score = abs(float(params.get("z_score", 0.0)))
        except (TypeError, ValueError):
            score = 0.0
        key = (p["meter_id"], p["timestamp_utc"])
        best[key] = max(best.get(key, 0.0), score)

    ranked = sorted(best.items(), key=lambda kv: kv[1], reverse=True)
    precisions: list[float] = []
    recalls: list[float] = []
    tp = 0
    for i, (key, _score) in enumerate(ranked, start=1):
        if key in truth_set:
            tp += 1
        precisions.append(tp / i)
        recalls.append(tp / len(truth_set))
    return calculate_pr_auc(precisions, recalls)


def evaluate_detection(
    conn: sqlite3.Connection,
    ground_truth_path: str,
    days: int = 90,
    buildings: int = 5,
) -> dict:
    """Calculate precision, recall, F1, PR-AUC, and false alert rate."""
    with open(ground_truth_path, encoding="utf-8") as f:
        truth = json.load(f)
    truth_set = {(t["meter_id"], t["timestamp"]) for t in truth}

    cursor = conn.execute(
        "SELECT meter_id, timestamp_utc, detection_parameters FROM anomalies"
    )
    predictions = cursor.fetchall()
    pred_set = {(p["meter_id"], p["timestamp_utc"]) for p in predictions}

    true_positives = len(truth_set.intersection(pred_set))
    false_positives = len(pred_set - truth_set)
    false_negatives = len(truth_set - pred_set)
    precision = (
        true_positives / (true_positives + false_positives)
        if (true_positives + false_positives) > 0
        else 0.0
    )
    recall = (
        true_positives / (true_positives + false_negatives)
        if (true_positives + false_negatives) > 0
        else 0.0
    )
    f1 = (
        2 * (precision * recall) / (precision + recall)
        if (precision + recall) > 0
        else 0.0
    )
    pr_auc = _ranked_pr_curve(predictions, truth_set)

    weeks = days / 7.0
    false_alerts_per_week = (
        false_positives / (buildings * weeks) if buildings > 0 else 0.0
    )

    return {
        "precision": round(precision, 3),
        "recall": round(recall, 3),
        "f1": round(f1, 3),
        "pr_auc": round(pr_auc, 3),
        "true_positives": true_positives,
        "false_positives": false_positives,
        "false_negatives": false_negatives,
        "false_alerts_per_bldg_week": round(false_alerts_per_week, 2),
    }


def evaluate_quality(
    conn: sqlite3.Connection,
    quality_truth_path: str = "quality_ground_truth.json",
) -> dict:
    """Calculate data quality defect counts and capture rates.

    If the simulator emitted quality_ground_truth.json, injected defect
    counts are compared against what ingestion actually caught.
    """
    cursor = conn.execute(
        "SELECT issue_type, count(*) AS c FROM data_quality_issues "
        "GROUP BY issue_type"
    )
    issues = {row["issue_type"]: row["c"] for row in cursor.fetchall()}
    result = {
        "duplicates_caught": issues.get("duplicate", 0),
        "invalid_units_caught": issues.get("invalid_unit", 0),
        "invalid_timestamps_caught": issues.get("invalid_timestamp", 0),
        "negative_consumption_caught": issues.get("negative_consumption", 0),
    }
    try:
        with open(quality_truth_path, encoding="utf-8") as f:
            truth = json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        return result
    injected_dupes = int(truth.get("duplicates", 0))
    result["duplicates_injected"] = injected_dupes
    result["missing_injected"] = int(truth.get("missing", 0))
    result["duplicate_capture_rate"] = (
        round(result["duplicates_caught"] / injected_dupes, 3)
        if injected_dupes > 0
        else 1.0
    )
    return result

def analyze_all(conn: sqlite3.Connection, *, create_incidents: bool = True) -> int:
    """Run both detectors over every valid reading.

    Passes the METER ID (not the reading id) to the detectors. Incidents are
    created only for anomalies whose data-quality window is eligible.
    Returns the number of anomalies detected.
    """
    cursor = conn.execute(
        "SELECT id, meter_id, timestamp_utc FROM energy_readings "
        "WHERE is_valid = 1 ORDER BY timestamp_utc"
    )
    readings = cursor.fetchall()
    detected = 0
    for r in readings:
        anomalies = [
            detect_rolling_baseline(conn, r["meter_id"], r["timestamp_utc"]),
            detect_robust_mad(conn, r["meter_id"], r["timestamp_utc"]),
        ]
        for anomaly in anomalies:
            if anomaly is None:
                continue
            detected += 1
            if create_incidents and anomaly.is_data_quality_eligible:
                create_incident(conn, anomaly)
    return detected

# Copyright 2026 Lightibulb
"""Before/after intervention verification engine."""
import dataclasses
import datetime as dt
import sqlite3
import statistics

from ecofac.timeutil import to_z


@dataclasses.dataclass
class VerificationResult:
    """Result of a before/after energy verification."""

    status: str
    baseline_mean: float
    post_mean: float
    percent_change: float
    data_completeness_pct: float
    caveats: list[str]


def verify_intervention(
    conn: sqlite3.Connection,
    meter_id: str,
    intervention_date: dt.datetime,
    baseline_days: int = 30,
    post_days: int = 14,
    *,
    threshold_pct: float = 5.0,
) -> VerificationResult:
    """Compare energy consumption before and after an intervention.

    Windows: baseline = [intervention - baseline_days, intervention);
    post = [intervention + 1 day, intervention + 1 day + post_days).
    All bounds are normalized to the canonical 'Z' storage form so string
    comparisons against SQLite TEXT timestamps are exact.
    """
    b_start = to_z(intervention_date - dt.timedelta(days=baseline_days))
    b_end = to_z(intervention_date)
    cursor = conn.execute(
        "SELECT value FROM energy_readings WHERE meter_id = ? "
        "AND timestamp_utc >= ? AND timestamp_utc < ? AND is_valid = 1",
        (meter_id, b_start, b_end),
    )
    baseline_vals = [row["value"] for row in cursor.fetchall()]

    p_start = to_z(intervention_date + dt.timedelta(days=1))
    p_end = to_z(intervention_date + dt.timedelta(days=1 + post_days))
    cursor = conn.execute(
        "SELECT value FROM energy_readings WHERE meter_id = ? "
        "AND timestamp_utc >= ? AND timestamp_utc < ? AND is_valid = 1",
        (meter_id, p_start, p_end),
    )
    post_vals = [row["value"] for row in cursor.fetchall()]

    expected_b = baseline_days * 24
    expected_p = post_days * 24
    completeness = (len(baseline_vals) + len(post_vals)) / (expected_b + expected_p) * 100
    caveats = [
        "Synthetic data only.",
        "Weather and occupancy variations are not controlled for.",
        "Not verified against real utility bills.",
    ]

    if not baseline_vals or not post_vals or completeness < 80.0:
        return VerificationResult(
            status="INCONCLUSIVE",
            baseline_mean=0.0,
            post_mean=0.0,
            percent_change=0.0,
            data_completeness_pct=round(completeness, 1),
            caveats=caveats,
        )

    b_mean = statistics.mean(baseline_vals)
    p_mean = statistics.mean(post_vals)
    pct_change = ((p_mean - b_mean) / b_mean) * 100.0 if b_mean > 0 else 0.0

    # Recurrence: a new spike in the post period
    b_stdev = statistics.stdev(baseline_vals) if len(baseline_vals) > 1 else 0.0
    spike_threshold = b_mean + max(3 * b_stdev, 0.2 * b_mean)
    has_recurrence = any(v > spike_threshold for v in post_vals)

    if has_recurrence:
        status = "RECURRENCE"
    elif pct_change <= -threshold_pct:
        status = "SUCCESSFUL"
    elif pct_change < 0:
        status = "PARTIAL_IMPROVEMENT"
    elif pct_change >= threshold_pct:
        status = "FAILED"
    else:
        status = "INCONCLUSIVE"

    return VerificationResult(
        status=status,
        baseline_mean=round(b_mean, 2),
        post_mean=round(p_mean, 2),
        percent_change=round(pct_change, 2),
        data_completeness_pct=round(completeness, 1),
        caveats=caveats,
    )

# Copyright 2026 Lightibulb

"""Reproducible synthetic data generator for EcoFac evaluation."""

import csv
import datetime as dt
import json
import math
import pathlib
import random


def generate_data(
    *,
    filename: str = "synthetic_data.csv",
    days: int = 90,
    buildings: int = 5,
    meters_per_bldg: int = 2,
    seed: int = 42,
    anomaly_prob: float = 0.01,
) -> None:
    """Generate synthetic CSV data and ground truth labels."""
    random.seed(seed)

    start_date = dt.datetime(2026, 1, 1, 0, 0, tzinfo=dt.UTC)
    readings = []
    ground_truth = []

    for b in range(1, buildings + 1):
        bldg_id = f"b{b}"
        for m in range(1, meters_per_bldg + 1):
            meter_id = f"m{b}-{m}"

            base_load = random.uniform(10.0, 50.0)
            seasonal_amp = random.uniform(5.0, 15.0)

            for day in range(days):
                current_date = start_date + dt.timedelta(days=day)
                is_weekend = current_date.weekday() >= 5

                # Stale data simulation (last 3 days of meter 2, building 3)
                if b == 3 and m == 2 and day >= days - 3:
                    continue

                for hour in range(24):
                    ts = current_date + dt.timedelta(hours=hour)
                    ts_str = ts.isoformat().replace("+00:00", "Z")

                    seasonal = math.sin(2 * math.pi * day / 90) * seasonal_amp
                    schedule = 5.0 if not is_weekend and 8 <= hour <= 18 else 0.0
                    noise = random.gauss(0, 1.0)

                    value = base_load + seasonal + schedule + noise

                    if random.random() < anomaly_prob and value > 0:
                        value *= random.uniform(1.5, 3.0)
                        ground_truth.append({
                            "building_id": bldg_id,
                            "meter_id": meter_id,
                            "timestamp": ts_str,
                            "type": "spike",
                        })

                    readings.append({
                        "timestamp": ts_str,
                        "building_id": bldg_id,
                        "meter_id": meter_id,
                        "energy_value": round(value, 2),
                        "unit": "kWh",
                    })

    readings = [r for r in readings if random.random() > 0.01]
    duplicates = random.sample(readings, int(len(readings) * 0.01))
    readings.extend(duplicates)
    random.shuffle(readings)

    path = pathlib.Path(filename)
    fields = ["timestamp", "building_id", "meter_id", "energy_value", "unit"]

    with path.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(readings)

    # Ensure ground_truth.json is always written in the same directory
    gt_path = path.parent / "ground_truth.json"
    with gt_path.open("w", encoding="utf-8") as f:
        json.dump(ground_truth, f, indent=2)

    print(
        f"Generated {len(readings)} readings and "
        f"{len(ground_truth)} ground truth anomalies."
    )

import os
import sqlite3
from collections.abc import Generator

from ecofac.persistence.database import init_db

# On Render, set ECOFAC_DB_PATH to a file on the mounted persistent disk
# (e.g. /opt/render/data/ecofac_api.db) so data survives redeploys.
DB_PATH = os.environ.get("ECOFAC_DB_PATH", "ecofac_api.db")

_initialized: set[str] = set()


def get_db() -> Generator[sqlite3.Connection, None, None]:
    """Yield a database connection for the request."""
    conn = sqlite3.connect(
        DB_PATH, isolation_level=None, check_same_thread=False, timeout=30
    )
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON;")
    if DB_PATH not in _initialized:
        init_db(conn)
        _initialized.add(DB_PATH)
    try:
        yield conn
    finally:
        conn.close()

                "INSERT OR IGNORE INTO meters "
                "(id, building_id, fuel_type, unit, created_at) "
                "VALUES (?, ?, 'elec', 'kWh', ?)",
                (f"m{b}-{m}", f"b{b}", now)
            )
    conn.execute(
        "INSERT OR IGNORE INTO data_sources (id, name, source_type, created_at) "
        "VALUES ('s1', 'Src', 'csv', ?)",
        (now,)
    )

    batch_id = f"batch-{now}"
    conn.execute(
        "INSERT OR IGNORE INTO import_batches "
        "(id, source_id, status, imported_at) VALUES (?, 's1', 'started', ?)",
        (batch_id, now)
    )

    # 3. Ingest
    summary = ingest_csv(conn, csv_content, "s1", batch_id)

    return {
        "status": "success",
        "message": f"Generated and ingested {summary.accepted_rows} rows."
    }

"""Endpoints for CSV imports."""

import csv
import dataclasses
import datetime as dt
import io
import json
import sqlite3
from typing import Annotated

from fastapi import APIRouter, Depends, File, Form, HTTPException, UploadFile

from ecofac.api.dependencies import get_db
from ecofac.api.schemas import ImportBatchResponse, ImportSummaryResponse
from ecofac.ingestion.pipeline import ingest_csv

router = APIRouter()

MAX_FILE_SIZE = 5 * 1024 * 1024  # 5 MB


@router.post("/imports", tags=["Imports"])
async def upload_csv(
    file: Annotated[UploadFile, File()],
    source_id: Annotated[str, Form()],
    batch_id: Annotated[str, Form()],
    conn: Annotated[sqlite3.Connection, Depends(get_db)],
) -> ImportSummaryResponse:
    """Upload a CSV file and ingest it."""
    content = await file.read()
    if len(content) > MAX_FILE_SIZE:
        raise HTTPException(status_code=413, detail="File too large")

    try:
        text = content.decode("utf-8")
    except UnicodeDecodeError as e:
        raise HTTPException(status_code=400, detail="File must be UTF-8 encoded") from e

    now = dt.datetime.now(dt.UTC).isoformat()

    # 1. Auto-create the data source
    conn.execute(
        "INSERT OR IGNORE INTO data_sources (id, name, source_type, created_at) "
        "VALUES (?, ?, 'csv', ?)",
        (source_id, source_id, now),
    )

    # 2. Auto-create the batch
    conn.execute(
        "INSERT OR IGNORE INTO import_batches (id, source_id, status, imported_at) "
        "VALUES (?, ?, 'started', ?)",
        (batch_id, source_id, now),
    )

    # 3. Extract buildings and meters from CSV and auto-create them
    try:
        reader = csv.DictReader(io.StringIO(text))
        pairs = {
            (row.get("building_id", "").strip(), row.get("meter_id", "").strip())
            for row in reader
        }

        # Create a default org
        conn.execute(
            "INSERT OR IGNORE INTO organizations (id, name, created_at) "
            "VALUES ('o-auto', 'Auto Org', ?)",
            (now,),
        )

        for b_id, m_id in pairs:
            if not b_id or not m_id:
                continue

            conn.execute(
                "INSERT OR IGNORE INTO buildings (id, org_id, name, created_at) "
                "VALUES (?, 'o-auto', ?, ?)",
                (b_id, b_id, now),
            )

            conn.execute(
                "INSERT OR IGNORE INTO meters "
                "(id, building_id, fuel_type, unit, created_at) "
                "VALUES (?, ?, 'elec', 'kWh', ?)",
                (m_id, b_id, now),
            )

    except (csv.Error, ValueError):
        # If we can't parse the CSV header, let ingest_csv handle the error properly
        pass

    # 4. Run ingestion
    try:
        summary = ingest_csv(conn, text, source_id, batch_id, max_size_mb=5.0)

        conn.execute(
            "UPDATE import_batches SET status = 'completed', summary_json = ? "
            "WHERE id = ?",
            (json.dumps(dataclasses.asdict(summary)), batch_id),
        )

        return ImportSummaryResponse(**dataclasses.asdict(summary))
    except ValueError as e:
        conn.execute(
            "UPDATE import_batches SET status = 'failed' WHERE id = ?", (batch_id,)
        )
        raise HTTPException(status_code=400, detail=str(e)) from e
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e)) from e

@router.get("/quality/{meter_id}", tags=["Intelligence"])
def get_quality(
    meter_id: str,
    start: Annotated[str, Query()],
    end: Annotated[str, Query()],
    conn: Annotated[sqlite3.Connection, Depends(get_db)],
) -> QualityResponse:
    """Assess data quality for a meter over a period."""
    try:
        start_dt = dt.datetime.fromisoformat(start)
        end_dt = dt.datetime.fromisoformat(end)
        if start_dt.tzinfo is None or end_dt.tzinfo is None:
            msg = "Naive timestamps not allowed"
            raise ValueError(msg)
    except ValueError as e:
        raise HTTPException(
            status_code=400,
            detail="Invalid ISO8601 date format (timezone required)"
        ) from e

    report = assess_quality(conn, meter_id, start_dt, end_dt)
    return QualityResponse(
        meter_id=report.meter_id,
        period_start=report.period_start,
        period_end=report.period_end,
        expected_readings=report.expected_readings,
        actual_readings=report.actual_readings,
        missing_readings=report.missing_readings,
        duplicate_readings=report.duplicate_readings,
        invalid_readings=report.invalid_readings,
        latest_observation=report.latest_observation,
        is_stale=report.is_stale,
        is_analysis_eligible=report.is_analysis_eligible,
        flags=report.flags
    )


@router.post("/analyze/{meter_id}", tags=["Intelligence"])
def analyze_meter(
    meter_id: str,
    timestamp: Annotated[str, Query()],
    conn: Annotated[sqlite3.Connection, Depends(get_db)],
) -> dict:
    """Run anomaly detection for a specific timestamp and create incidents."""
    try:
        ts_dt = dt.datetime.fromisoformat(timestamp)
        if ts_dt.tzinfo is None:
            msg = "Naive timestamps not allowed"
            raise ValueError(msg)
    except ValueError as e:
        raise HTTPException(
            status_code=400,
            detail="Invalid ISO8601 date format (timezone required)"
        ) from e

    anomaly_roll = detect_rolling_baseline(conn, meter_id, timestamp)
    anomaly_mad = detect_robust_mad(conn, meter_id, timestamp)

    results = []
    for anomaly in [anomaly_roll, anomaly_mad]:
        if anomaly:
            incident_id = create_incident(conn, anomaly)
            results.append({
                "anomaly_id": anomaly.id,
                "incident_id": incident_id,
                "detector": anomaly.detector_name,
                "severity": anomaly.severity,
                "gated_by_quality": not anomaly.is_data_quality_eligible,
            })

    if not results:
        return {"status": "no_anomalies_detected"}

    return {"status": "anomalies_detected", "findings": results}

# Copyright 2026 Lightibulb
"""Statistical anomaly detection engines."""
import datetime as dt
import json
import sqlite3
import statistics
import uuid

from ecofac.domain.models import Anomaly
from ecofac.quality.assessment import assess_quality
from ecofac.timeutil import now_z, parse_utc

ROLLING_Z_THRESHOLD = 3.0
ROLLING_Z_HIGH = 4.5
MAD_Z_THRESHOLD = 3.5
MAD_Z_HIGH = 5.0
ZERO_MAD_EPSILON = 1e-6


def detect_rolling_baseline(
    conn: sqlite3.Connection,
    meter_id: str,
    target_ts: str,
    window_size: int = 24,
) -> Anomaly | None:
    """Detect anomalies using a rolling window mean and standard deviation."""
    cursor = conn.execute(
        "SELECT id, timestamp_utc, value FROM energy_readings "
        "WHERE meter_id = ? AND timestamp_utc < ? AND is_valid = 1 "
        "ORDER BY timestamp_utc DESC LIMIT ?",
        (meter_id, target_ts, window_size),
    )
    history = cursor.fetchall()
    if len(history) < window_size:
        return None
    values = [row["value"] for row in history]
    obs_ids = [row["id"] for row in history]

    cursor = conn.execute(
        "SELECT energy_readings.id, energy_readings.value, meters.building_id "
        "FROM energy_readings JOIN meters ON meters.id = energy_readings.meter_id "
        "WHERE energy_readings.meter_id = ? AND energy_readings.timestamp_utc = ? "
        "AND energy_readings.is_valid = 1",
        (meter_id, target_ts),
    )
    target = cursor.fetchone()
    if not target:
        return None

    mean = statistics.mean(values)
    stdev = statistics.stdev(values) if len(values) > 1 else 0.0
    observed = target["value"]
    deviation = observed - mean
    if stdev == 0.0:
        stdev = ZERO_MAD_EPSILON
    z_score = deviation / stdev
    if abs(z_score) < ROLLING_Z_THRESHOLD:
        return None

    return _build_anomaly(
        building_id=target["building_id"],
        meter_id=meter_id,
        target_ts=target_ts,
        observed=observed,
        expected=mean,
        detector_name="rolling_baseline",
        severity="high" if abs(z_score) > ROLLING_Z_HIGH else "medium",
        params={"window_size": window_size, "z_score": z_score, "stdev": stdev},
        supporting_ids=obs_ids,
        conn=conn,
    )


def detect_robust_mad(
    conn: sqlite3.Connection,
    meter_id: str,
    target_ts: str,
    window_size: int = 24,
) -> Anomaly | None:
    """Detect anomalies using Median and Median Absolute Deviation (MAD)."""
    cursor = conn.execute(
        "SELECT id, timestamp_utc, value FROM energy_readings "
        "WHERE meter_id = ? AND timestamp_utc < ? AND is_valid = 1 "
        "ORDER BY timestamp_utc DESC LIMIT ?",
        (meter_id, target_ts, window_size),
    )
    history = cursor.fetchall()
    if len(history) < window_size:
        return None
    values = [row["value"] for row in history]
    obs_ids = [row["id"] for row in history]

    cursor = conn.execute(
        "SELECT energy_readings.id, energy_readings.value, meters.building_id "
        "FROM energy_readings JOIN meters ON meters.id = energy_readings.meter_id "
        "WHERE energy_readings.meter_id = ? AND energy_readings.timestamp_utc = ? "
        "AND energy_readings.is_valid = 1",
        (meter_id, target_ts),
    )
    target = cursor.fetchone()
    if not target:
        return None

    median = statistics.median(values)
    absolute_deviations = [abs(v - median) for v in values]
    mad = statistics.median(absolute_deviations)
    observed = target["value"]
    deviation = observed - median
    scaled_mad = 1.4826 * mad
    if scaled_mad == 0.0:
        scaled_mad = ZERO_MAD_EPSILON
    z_score = deviation / scaled_mad
    if abs(z_score) < MAD_Z_THRESHOLD:
        return None

    return _build_anomaly(
        building_id=target["building_id"],
        meter_id=meter_id,
        target_ts=target_ts,
        observed=observed,
        expected=median,
        detector_name="robust_mad",
        severity="high" if abs(z_score) > MAD_Z_HIGH else "medium",
        params={"window_size": window_size, "z_score": z_score, "mad": mad},
        supporting_ids=obs_ids,
        conn=conn,
    )


def _build_anomaly(
    *,
    building_id: str,
    meter_id: str,
    target_ts: str,
    observed: float,
    expected: float,
    detector_name: str,
    severity: str,
    params: dict,
    supporting_ids: list[str],
    conn: sqlite3.Connection,
) -> Anomaly | None:
    """Construct the anomaly record and check data quality eligibility.

    Returns None if this (meter, timestamp, detector) was already flagged,
    so re-analysis cannot spawn duplicate anomalies or incidents.
    """
    existing = conn.execute(
        "SELECT 1 FROM anomalies "
        "WHERE meter_id = ? AND timestamp_utc = ? AND detector_name = ?",
        (meter_id, target_ts, detector_name),
    ).fetchone()
    if existing:
        return None

    abs_dev = observed - expected
    pct_dev = (abs_dev / expected * 100) if expected > 0 else None
    target_dt = parse_utc(target_ts)
    start_dt = target_dt - dt.timedelta(hours=1)
    quality = assess_quality(conn, meter_id, start_dt, target_dt, expected_frequency_minutes=60)

    anomaly = Anomaly(
        id=str(uuid.uuid4()),
        building_id=building_id,
        meter_id=meter_id,
        timestamp_utc=target_ts,
        observed_consumption=observed,
        expected_consumption=expected,
        absolute_deviation=abs_dev,
        percentage_deviation=pct_dev,
        detector_name=detector_name,
        severity=severity,
        is_data_quality_eligible=quality.is_analysis_eligible,
        detection_timestamp=now_z(),
        supporting_observation_ids=supporting_ids,
        detection_parameters=json.dumps(params),
    )
    conn.execute(
        "INSERT INTO anomalies (id, building_id, meter_id, timestamp_utc, "
        "observed_consumption, expected_consumption, absolute_deviation, "
        "percentage_deviation, detector_name, severity, "
        "is_data_quality_eligible, detection_timestamp, detection_parameters) "
        "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
        (
            anomaly.id,
            anomaly.building_id,
            anomaly.meter_id,

# Copyright 2026 Lightibulb

"""Builds reproducible evidence records for anomalies."""

import json
import sqlite3

from ecofac.domain.models import Anomaly


def build_computation_log(conn: sqlite3.Connection, anomaly: Anomaly) -> str:
    """Construct a JSON evidence payload, validating all reading references."""
    # 1. Validate that all supporting observation IDs actually exist
    supporting_ids = anomaly.supporting_observation_ids
    if not supporting_ids:
        msg = "Anomaly has no supporting observations."
        raise ValueError(msg)

    placeholders = ",".join(["?"] * len(supporting_ids))
    query = (
        "SELECT id, timestamp_utc, value, raw_value, source_id "
        "FROM energy_readings "
        f"WHERE id IN ({placeholders})"
    )

    cursor = conn.execute(query, supporting_ids)
    rows = cursor.fetchall()

    if len(rows) != len(supporting_ids):
        msg = "Supporting observation IDs reference nonexistent readings."
        raise ValueError(msg)

    # 2. Identify the target reading
    cursor = conn.execute(
        "SELECT id, timestamp_utc, value, raw_value FROM energy_readings "
        "WHERE meter_id = ? AND timestamp_utc = ?",
        (anomaly.meter_id, anomaly.timestamp_utc),
    )
    target = cursor.fetchone()
    if not target:
        msg = "Target reading does not exist."
        raise ValueError(msg)

    # 3. Assemble the reproducible payload
    payload = {
        "detector_name": anomaly.detector_name,
        "detector_configuration": json.loads(anomaly.detection_parameters),
        "observation_timestamp": anomaly.timestamp_utc,
        "target_measurement": {
            "id": target["id"],
            "value": target["value"],
            "raw_value": target["raw_value"],
        },
        "baseline_calculation": {
            "expected_value": anomaly.expected_consumption,
            "absolute_deviation": anomaly.absolute_deviation,
            "percentage_deviation": anomaly.percentage_deviation,
        },
        "historical_comparison_window": [
            {
                "id": r["id"],
                "timestamp": r["timestamp_utc"],
                "value": r["value"],
                "source_id": r["source_id"],
            } for r in rows
        ],
        "data_quality_eligible": anomaly.is_data_quality_eligible,
    }

    return json.dumps(payload, indent=2)

# Copyright 2026 Lightibulb

"""Manages incident state transitions and audit logging."""

import datetime as dt
import sqlite3
import uuid

from ecofac.domain.models import Anomaly
from ecofac.evidence.builder import build_computation_log

VALID_TRANSITIONS = {
    "DETECTED": ["UNDER_REVIEW"],
    "UNDER_REVIEW": ["ACKNOWLEDGED", "DISMISSED"],
    "ACKNOWLEDGED": ["RESOLVED", "UNRESOLVED"],
    "DISMISSED": [],       # Terminal
    "RESOLVED": [],        # Terminal
    "UNRESOLVED": [],      # Terminal
}


class InvalidStateTransitionError(Exception):
    """Raised when an invalid incident status transition is attempted."""


def _log_audit(
    conn: sqlite3.Connection,
    entity_id: str,
    action: str,
    details: str,
) -> None:
    """Append an immutable audit event."""
    conn.execute(
        "INSERT INTO audit_events (id, entity_type, entity_id, action, details, created_at) "
        "VALUES (?, ?, ?, ?, ?, ?)",
        (
            str(uuid.uuid4()),
            "INCIDENT",
            entity_id,
            action,
            details,
            dt.datetime.now(dt.UTC).isoformat(),
        ),
    )


def create_incident(conn: sqlite3.Connection, anomaly: Anomaly) -> str:
    """Create an incident and its associated evidence record."""
    incident_id = str(uuid.uuid4())
    now = dt.datetime.now(dt.UTC).isoformat()

    # Build evidence first (validates reading existence)
    try:
        computation_log = build_computation_log(conn, anomaly)
    except ValueError as e:
        msg = f"Cannot create incident: {e}"
        raise ValueError(msg) from e

    conn.execute("BEGIN")
    try:
        conn.execute(
            "INSERT INTO incidents (id, anomaly_id, status, created_at, updated_at) "
            "VALUES (?, ?, ?, ?, ?)",
            (incident_id, anomaly.id, "DETECTED", now, now),
        )

        conn.execute(
            "INSERT INTO evidence_records (id, incident_id, computation_log, created_at) "
            "VALUES (?, ?, ?, ?)",
            (str(uuid.uuid4()), incident_id, computation_log, now),
        )

        _log_audit(
            conn,
            incident_id,
            "CREATED",
            f"Incident created from anomaly {anomaly.id} with {anomaly.detector_name}",
        )
        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise

    return incident_id


def transition_incident(
    conn: sqlite3.Connection,
    incident_id: str,
    new_status: str,
    reason: str | None = None,
) -> None:
    """Advance the incident state, enforcing rules and logging audit events."""
    cursor = conn.execute("SELECT status FROM incidents WHERE id = ?", (incident_id,))
    row = cursor.fetchone()
    if not row:
        msg = f"Incident {incident_id} not found."
        raise ValueError(msg)

    current_status = row["status"]
    allowed = VALID_TRANSITIONS.get(current_status, [])

    if new_status not in allowed:
        msg = f"Invalid transition from {current_status} to {new_status}."
        raise InvalidStateTransitionError(msg)

    if new_status in ("RESOLVED", "UNRESOLVED") and not reason:
        msg = f"A reason is required to transition to {new_status}."
        raise ValueError(msg)

    if new_status == "DISMISSED" and not reason:
        msg = "A dismissal reason is required."
        raise ValueError(msg)

    now = dt.datetime.now(dt.UTC).isoformat()

    conn.execute("BEGIN")
    try:
        if new_status == "DISMISSED":
            conn.execute(
                "UPDATE incidents SET status = ?, dismissal_reason = ?, "
                "updated_at = ? WHERE id = ?",
                (new_status, reason, now, incident_id),
            )
        elif new_status in ("RESOLVED", "UNRESOLVED"):
            conn.execute(
                "UPDATE incidents SET status = ?, resolution_notes = ?, "
                "updated_at = ? WHERE id = ?",
                (new_status, reason, now, incident_id),
            )
        else:
            conn.execute(
                "UPDATE incidents SET status = ?, updated_at = ? WHERE id = ?",
                (new_status, now, incident_id),
            )

        _log_audit(
            conn,
            incident_id,
            f"TRANSITION_{new_status}",
            f"Status changed to {new_status}. Reason: {reason or 'None'}",
        )
        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise

# Copyright 2026 Lightibulb
"""CSV ingestion and normalization pipeline."""
import csv
import dataclasses
import datetime as dt
import io
import sqlite3
import uuid


@dataclasses.dataclass
class IngestionSummary:
    """Summary of a CSV ingestion run."""

    total_rows: int = 0
    accepted_rows: int = 0
    rejected_rows: int = 0
    duplicate_rows: int = 0
    invalid_timestamps: int = 0
    invalid_units: int = 0
    unknown_meter_ids: int = 0
    negative_consumption: int = 0


UNITS = {"wh": 0.001, "kwh": 1.0, "mwh": 1000.0}


def _issue_row(
    batch_id: str,
    issue_type: str,
    description: str,
    *,
    reading_id: str | None = None,
    meter_id: str | None = None,
    reading_timestamp_utc: str | None = None,
) -> tuple:
    """Build one data_quality_issues row."""
    return (
        str(uuid.uuid4()),
        reading_id,
        batch_id,
        issue_type,
        description,
        dt.datetime.now(dt.UTC).isoformat(),
        meter_id,
        reading_timestamp_utc,
    )


def _existing_pairs(
    conn: sqlite3.Connection, meter_ids: list[str]
) -> set[tuple[str, str]]:
    """Fetch (meter_id, timestamp_utc) pairs already stored, chunked."""
    unique_meters = sorted(set(meter_ids))
    existing: set[tuple[str, str]] = set()
    chunk_size = 500
    for i in range(0, len(unique_meters), chunk_size):
        chunk = unique_meters[i:i + chunk_size]
        placeholders = ",".join("?" * len(chunk))
        cursor = conn.execute(
            f"SELECT meter_id, timestamp_utc FROM energy_readings "
            f"WHERE meter_id IN ({placeholders})",
            chunk,
        )
        existing.update(
            (row["meter_id"], row["timestamp_utc"]) for row in cursor.fetchall()
        )
    return existing


def ingest_csv(
    conn: sqlite3.Connection,
    csv_content: str,
    source_id: str,
    batch_id: str,
    *,
    max_rows: int = 50000,
    max_size_mb: float = 5.0,
) -> IngestionSummary:
    """Parse, validate, and store readings from a CSV string.

    Valid readings and quality issues are bulk-inserted with executemany so
    large imports stay fast on slow hosts (e.g. Render free tier).
    """
    if len(csv_content) > max_size_mb * 1024 * 1024:
        msg = "File size exceeds limit"
        raise ValueError(msg)

    reader = csv.DictReader(io.StringIO(csv_content))
    required = {"timestamp", "building_id", "meter_id", "energy_value", "unit"}
    if not reader.fieldnames or not required.issubset(reader.fieldnames):
        msg = f"Missing required columns. Expected: {required}"
        raise ValueError(msg)

    summary = IngestionSummary()
    cursor = conn.execute("SELECT id, building_id FROM meters")
    meter_map = {row["id"]: row["building_id"] for row in cursor.fetchall()}

    seen: set[tuple[str, str]] = set()
    pending: list[tuple] = []
    issues: list[tuple] = []

    conn.execute("BEGIN")
    try:
        for row in reader:
            summary.total_rows += 1
            if summary.total_rows > max_rows:
                msg = "Row count exceeds limit"
                raise ValueError(msg)

            meter_id = (row.get("meter_id") or "").strip()
            building_id = (row.get("building_id") or "").strip()

            # 1. Validate meter and building relationship
            if meter_id not in meter_map:
                summary.rejected_rows += 1
                summary.unknown_meter_ids += 1
                issues.append(_issue_row(
                    batch_id, "unknown_meter", f"Unknown meter: {meter_id}",
                ))
                continue
            if meter_map[meter_id] != building_id:
                summary.rejected_rows += 1
                issues.append(_issue_row(
                    batch_id,
                    "building_mismatch",
                    f"Meter {meter_id} does not belong to building {building_id}",
                ))
                continue

            # 2. Normalize Timestamp to UTC (naive timestamps are rejected)
            ts_raw = (row.get("timestamp") or "").strip()
            try:
                dt_val = dt.datetime.fromisoformat(ts_raw)
                if dt_val.tzinfo is None:
                    msg = f"Naive timestamp: {ts_raw}"
                    raise ValueError(msg)
                dt_utc = dt_val.astimezone(dt.UTC)
                ts_utc = dt_utc.isoformat().replace("+00:00", "Z")
            except ValueError:
                summary.rejected_rows += 1
                summary.invalid_timestamps += 1
                issues.append(_issue_row(
                    batch_id, "invalid_timestamp", f"Invalid timestamp: {ts_raw}",
                ))
                continue

            # 3. Duplicate check (within CSV)
            key = (meter_id, ts_utc)
            if key in seen:
                summary.rejected_rows += 1
                summary.duplicate_rows += 1
                issues.append(_issue_row(
                    batch_id, "duplicate",
                    f"Duplicate in CSV: {meter_id} @ {ts_utc}",
                    meter_id=meter_id, reading_timestamp_utc=ts_utc,
                ))
                continue
            seen.add(key)

            # 4. Unit normalization
            unit_raw = (row.get("unit") or "").strip().lower()
            if unit_raw not in UNITS:
                summary.rejected_rows += 1
                summary.invalid_units += 1
                issues.append(_issue_row(
                    batch_id, "invalid_unit", f"Unsupported unit: {unit_raw}",
                ))
                continue

            # 5. Value parsing
            val_raw = (row.get("energy_value") or "").strip()
            try:
                val = float(val_raw)
            except ValueError:
                summary.rejected_rows += 1
                issues.append(_issue_row(
                    batch_id, "malformed_value", f"Invalid value: {val_raw}",
                ))
                continue

            val_kwh = val * UNITS[unit_raw]
            reading_id = str(uuid.uuid4())
            is_valid = 1

            # 6. Negative consumption flagging
            if val_kwh < 0:
                is_valid = 0
                summary.negative_consumption += 1
                issues.append(_issue_row(
                    batch_id,
                    "negative_consumption",
                    f"Negative reading: {val_kwh} kWh",
                    reading_id=reading_id,
                    meter_id=meter_id,
                    reading_timestamp_utc=ts_utc,
                ))

            pending.append((
                reading_id, meter_id, ts_utc, val_kwh, "kWh", source_id,
                batch_id, is_valid, dt.datetime.now(dt.UTC).isoformat(), val_raw,
            ))

        # 7. Filter rows that already exist in the DB (bulk duplicate check)
        existing = _existing_pairs(conn, [r[1] for r in pending])
        final = []
        for rec in pending:
            if (rec[1], rec[2]) in existing:
                summary.rejected_rows += 1
                summary.duplicate_rows += 1
                issues.append(_issue_row(
                    batch_id, "duplicate",
                    f"Duplicate in DB: {rec[1]} @ {rec[2]}",
                    meter_id=rec[1], reading_timestamp_utc=rec[2],
                ))
            else:
                final.append(rec)
        summary.accepted_rows = len(final)

        # 8. Bulk insert readings first, then issues (issues may reference
        #    reading ids, so the FK requires this order)
        if final:
            conn.executemany(
                """INSERT INTO energy_readings
                (id, meter_id, timestamp_utc, value, unit, source_id, batch_id,
                is_valid, created_at, raw_value)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)""",
                final,
            )
        if issues:
            conn.executemany(
                """INSERT INTO data_quality_issues
                (id, reading_id, batch_id, issue_type, description, created_at,
                meter_id, reading_timestamp_utc)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?)""",
                issues,
            )

        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise

    return summary

import pathlib

def get_connection(db_path: str) -> sqlite3.Connection:
    """Create a connection with explicit transaction control."""
    # isolation_level=None disables implicit transactions, allowing explicit BEGIN/COMMIT
    conn = sqlite3.connect(db_path, isolation_level=None, check_same_thread=False)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON;")
    return conn


def init_db(conn: sqlite3.Connection) -> None:
    """Initialize the database with the schema."""
    schema_path = pathlib.Path(__file__).parent / "schema.sql"
    schema_sql = schema_path.read_text(encoding="utf-8")
    conn.executescript(schema_sql)

"""CRUD operations for domain entities."""

import sqlite3

from ecofac.domain.models import EnergyReading


class DuplicateReadingError(Exception):
    """Raised when a reading for a meter at a specific timestamp already exists."""


def insert_reading(conn: sqlite3.Connection, reading: EnergyReading) -> None:
    """Insert a reading safely, rolling back on duplicate."""
    try:
        conn.execute("BEGIN")
        conn.execute(
            """
            INSERT INTO energy_readings
            (id, meter_id, timestamp_utc, value, unit, source_id, batch_id, is_valid, created_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
            """,
            (
                reading.id,
                reading.meter_id,
                reading.timestamp_utc,
                reading.value,
                reading.unit,
                reading.source_id,
                reading.batch_id,
                int(reading.is_valid),
                reading.created_at,
            ),
        )
        conn.execute("COMMIT")
    except sqlite3.IntegrityError as e:
        conn.execute("ROLLBACK")
        msg = f"Reading for meter {reading.meter_id} at {reading.timestamp_utc} already exists."
        raise DuplicateReadingError(msg) from e

# Copyright 2026 Lightibulb
"""Data quality assessment engine."""
import dataclasses
import datetime as dt
import sqlite3

from ecofac.timeutil import parse_utc, to_z


@dataclasses.dataclass
class QualityReport:
    """Represents the quality assessment of a meter's data over a period."""

    meter_id: str
    period_start: str
    period_end: str
    expected_readings: int
    actual_readings: int
    missing_readings: int
    duplicate_readings: int
    invalid_readings: int
    latest_observation: str | None
    is_stale: bool
    is_analysis_eligible: bool
    flags: list[str]


def assess_quality(
    conn: sqlite3.Connection,
    meter_id: str,
    period_start: dt.datetime,
    period_end: dt.datetime,
    expected_frequency_minutes: int = 60,
) -> QualityReport:
    """Evaluate data quality for a meter over a specific time period.

    Bounds must be timezone-aware; naive datetimes are rejected loudly
    instead of being silently misinterpreted.
    """
    start_str = to_z(period_start)
    end_str = to_z(period_end)

    # 1. Fetch actual readings inside the window
    cursor = conn.execute(
        "SELECT timestamp_utc, is_valid FROM energy_readings "
        "WHERE meter_id = ? AND timestamp_utc >= ? AND timestamp_utc <= ? "
        "ORDER BY timestamp_utc ASC",
        (meter_id, start_str, end_str),
    )
    rows = cursor.fetchall()
    actual = len(rows)
    invalid = sum(1 for r in rows if r["is_valid"] == 0)
    latest_obs = rows[-1]["timestamp_utc"] if rows else None

    # 2. Expected vs missing
    duration_minutes = (period_end - period_start).total_seconds() / 60.0
    expected = int(duration_minutes / expected_frequency_minutes) + 1
    missing = max(0, expected - actual)

    # 3. Duplicates: scoped to THIS meter and THIS period (typed columns,
    #    not substring matching on free-text descriptions).
    cursor = conn.execute(
        "SELECT count(*) AS c FROM data_quality_issues "
        "WHERE issue_type = 'duplicate' AND meter_id = ? "
        "AND reading_timestamp_utc >= ? AND reading_timestamp_utc <= ?",
        (meter_id, start_str, end_str),
    )
    duplicates = cursor.fetchone()["c"]

    # 4. Freshness / staleness
    is_stale = False
    if not latest_obs:
        is_stale = True
    else:
        latest_dt = parse_utc(latest_obs)
        threshold_seconds = expected_frequency_minutes * 60 * 2
        if (period_end - latest_dt).total_seconds() > threshold_seconds:
            is_stale = True

    # 5. Flags
    flags = []
    if missing > 0:
        flags.append("missing_data")
    if duplicates > 0:
        flags.append("duplicate_data")
    if invalid > 0:
        flags.append("invalid_data")
    if is_stale:
        flags.append("stale_data")
    is_eligible = len(flags) == 0

    return QualityReport(
        meter_id=meter_id,
        period_start=start_str,
        period_end=end_str,
        expected_readings=expected,
        actual_readings=actual,
        missing_readings=missing,
        duplicate_readings=duplicates,
        invalid_readings=invalid,
        latest_observation=latest_obs,
        is_stale=is_stale,
        is_analysis_eligible=is_eligible,
        flags=flags,
    )

async function api(url, opts) {
  let res;
  try { res = await fetch(url, opts); }
  catch (err) { throw new Error("Can't reach the server. Check your connection and try again."); }
  const text = await res.text();
  let body;
  try { body = JSON.parse(text); } catch (err) { body = { detail: text || res.statusText }; }
  if (!res.ok) {
    let d = body && body.detail;
    if (d && typeof d !== "string") d = JSON.stringify(d);
    throw new Error(`Server error ${res.status}: ${d || "request failed"}`);
  }
  return body;
}

function timeAgo(iso) {
  const d = new Date(iso);
  if (isNaN(d)) return "";
  const s = Math.round((Date.now() - d) / 1000);
  for (const [unit, sec] of [["day", 86400], ["hour", 3600], ["minute", 60]]) {
    if (Math.abs(s) >= sec) return rtf.format(-Math.round(s / sec), unit);
  }
  return "just now";
}

function countTo(el, to) {
  const from = el._v ?? 0; el._v = to;
  cancelAnimationFrame(el._raf);
  if (reduceMotion || from === to) { el.textContent = nf.format(to); return; }

    if (p < 1) el._raf = requestAnimationFrame(step);
  };
  el._raf = requestAnimationFrame(step);
}

function buildChart() {
  if (chart) { chart.destroy(); chart = null; }
  if (typeof Chart === "undefined" || !fullData) return;
  Chart.defaults.font.family = '"DM Sans", system-ui, sans-serif';
  const { labels, values } = view(), accent = cssVar("--accent"), muted = cssVar("--muted"), line = cssVar("--line"), bar = cType === "bar";
  chart = new Chart($("#chart").getContext("2d"), {
    type: cType,
    plugins: chartPlugins,
    data: { labels, datasets: [{
      label: "Consumption (kWh)", data: values, borderColor: accent, borderWidth: bar ? 0 : 2.5, tension: 0.38, fill: true,
      pointRadius: 0, pointHoverRadius: 6, pointHoverBackgroundColor: cssVar("--paper"), pointHoverBorderColor: accent, pointHoverBorderWidth: 2,
      borderRadius: 4, borderSkipped: false, hoverBackgroundColor: accent,
      backgroundColor: (ctx) => {
        const a = ctx.chart.chartArea;
        if (bar || !a) return rgba(accent, bar ? 0.72 : 0.2);
        const g = ctx.chart.ctx.createLinearGradient(0, a.top, 0, a.bottom);
        g.addColorStop(0, rgba(accent, 0.38)); g.addColorStop(1, rgba(accent, 0));
        return g;
      }
    }] },
    options: {
      responsive: true, maintainAspectRatio: false, layout: { padding: { top: 20, right: 6 } },
      animation: {
        duration: reduceMotion ? 0 : 1300, easing: "easeOutQuart",
        onProgress(c) { if (!c.chart._done) c.chart._p = c.currentStep / c.numSteps; },
        onComplete(c) { c.chart._done = true; c.chart._p = 1; }
      },
      interaction: { mode: "index", intersect: false },
      plugins: {
        legend: { display: false },
        tooltip: {
          backgroundColor: cssVar("--ink"), titleColor: cssVar("--paper"), bodyColor: cssVar("--paper"), footerColor: cssVar("--paper"),
          displayColors: false, padding: 12, cornerRadius: 8, caretSize: 0,
          callbacks: {
            label: (c) => kwh.format(c.parsed.y) + " kWh",
            afterLabel: (c) => { const avg = avgOf(c.dataset.data), d = ((c.parsed.y - avg) / avg) * 100; return (d >= 0 ? "+" : "") + Math.round(d) + "% vs average"; }
          }
        }
      },
      scales: {
        x: { grid: { display: false }, ticks: { color: muted, maxRotation: 0, autoSkip: true, maxTicksLimit: 6 }, border: { color: line } },
        y: { beginAtZero: true, grid: { color: line }, ticks: { color: muted, maxTicksLimit: 5, callback: (v) => compact.format(v) }, border: { display: false } }
      }
    }
  });
  chart._p = reduceMotion ? 1 : 0;
}

async function loadIncidents() {
  const list = await api("/api/v1/incidents?limit=10");
  const ul = $("#incidents");
  const key = JSON.stringify(list);
  if (key === incKey) {
    ul.querySelectorAll("time[datetime]").forEach((t) => { t.textContent = timeAgo(t.getAttribute("datetime")); });
    return;
  }
  incKey = key;
  if (!Array.isArray(list) || list.length === 0) {
    renderMix([]);
    ul.innerHTML = '<li class="empty">No incidents yet. Generate demo data or add a CSV to see them here.</li>';
    return;
  }
  renderMix(list);
  ul.innerHTML = list.map((inc, i) => {
    const next = NEXT[inc.status];
    const when = new Date(inc.created_at);
    return `<li class="inc" style="--i:${i}">
      <span class="pill ${PILL[inc.status] || "ok"}">${esc(nice(inc.status))}</span>
      <span class="inc-id" title="${esc(inc.id)}">${esc(String(inc.id).slice(0, 8))}</span>
      <time class="inc-time" datetime="${esc(inc.created_at)}" title="${isNaN(when) ? "" : esc(when.toLocaleString())}">${esc(timeAgo(inc.created_at))}</time>
      <span class="inc-act">${next ? `<button class="btn small" type="button" data-id="${esc(inc.id)}" data-path="${next.path}" data-done="${esc(next.done)}">${next.label}</button>` : ""}</span>
    </li>`;
  }).join("");
}

async function refreshAll() {
  const results = await Promise.allSettled([loadStats(), loadChart(), loadIncidents()]);
  const failed = results.filter((r) => r.status === "rejected");

  }
  return failed;
}

async function upload(file) {
  if (!file) return;
  if (!/\.csv$/i.test(file.name)) { say("That file isn't a .csv. Choose a CSV file.", "bad"); return; }
  const fd = new FormData();
  fd.append("file", file);
  fd.append("source_id", "dashboard-upload");
  fd.append("batch_id", "batch-" + Date.now());
  say(`Uploading ${file.name}…`, "busy");
  try {
    const d = await api("/api/v1/imports", { method: "POST", body: fd });
    say(`Imported ${nf.format(d.accepted_rows ?? 0)} rows. ${nf.format(d.rejected_rows ?? 0)} rejected.`, "good");
    toast("CSV imported");
    await refreshAll();
  } catch (err) {
    say(err.message, "bad");
  } finally {
    fileInput.value = "";
  }
}

async function load(){
  try{
    const r=await fetch(DATA_URL+"?t="+Date.now(),{cache:"no-store"});
    if(!r.ok)throw new Error("HTTP "+r.status);
    snapshot=await r.json();
    render();
    el("status").textContent="updated "+snapshot.generated_at;

        let chartInstance = null;

        // Read a response safely: the server may return plain text (e.g. on a 500), not JSON.
        async function readBody(res) {
            const text = await res.text();
            try { return JSON.parse(text); } catch (e) { return { detail: text || res.statusText }; }
        }

        function errorMessage(res, body) {
            let detail = body && body.detail;
            if (detail && typeof detail !== 'string') { detail = JSON.stringify(detail); }
            return `HTTP ${res.status}: ${detail || 'Request failed'}`;
        }

        async function fetchStats() {
            const res = await fetch('/api/v1/dashboard/stats');
            if (!res.ok) { console.error('stats failed', res.status); return; }
            const data = await res.json();
            document.getElementById('stat-buildings').innerText = data.buildings;
            document.getElementById('stat-meters').innerText = data.meters;
            document.getElementById('stat-open').innerText = data.open_incidents;
            document.getElementById('stat-total').innerText = data.total_incidents;
        }

        async function fetchChart() {
            const res = await fetch('/api/v1/dashboard/chart-data');
            if (!res.ok) { console.error('chart-data failed', res.status); return; }
            const data = await res.json();
            
            const ctx = document.getElementById('energyChart').getContext('2d');
            
            if (chartInstance) { chartInstance.destroy(); }

            chartInstance = new Chart(ctx, {
                type: 'line',
                data: {
                    labels: data.labels,
                    datasets: [{
                        label: 'Consumption (kWh)',
                        data: data.data,
                        borderColor: '#10b981',
                        backgroundColor: 'rgba(16, 185, 129, 0.1)',
                        borderWidth: 2,
                        fill: true,
                        tension: 0.4
                    }]

                options: {

                    plugins: { legend: { display: false } },

                        y: { grid: { color: 'rgba(255,255,255,0.05)' }, ticks: { color: '#94a3b8' } }
                    }
                }
            });
        }

        async function fetchIncidents() {
            const res = await fetch('/api/v1/incidents?limit=10');
            if (!res.ok) { console.error('incidents failed', res.status); return; }
            const incidents = await res.json();
            const tbody = document.getElementById('incidents-table');
            
            if (incidents.length === 0) {
                tbody.innerHTML = '<tr><td colspan="4" class="py-4 text-center text-slate-500">No incidents found. Generate demo data first.</td></tr>';
                return;

            tbody.innerHTML = incidents.map(inc => `

                        </span>
                    </td>

                </tr>

                    fetchStats();

                btn.innerText = "Generate Demo Data";

            formData.append("source_id", "dashboard-upload");

                    fetchIncidents();

                    statusDiv.className = "mt-4 text-sm text-center text-red-400";
                }

                statusDiv.innerText = "Network error: could not reach the server.";
                statusDiv.className = "mt-4 text-sm text-center text-red-400";
            } finally {
                input.value = "";  // allow re-selecting the same file
            }
        }

async function api(url, opts) {
  let res;
  try { res = await fetch(url, opts); }
  catch (err) { throw new Error("Can't reach the server. Check your connection and try again."); }
  const text = await res.text();
  let body;
  try { body = JSON.parse(text); } catch (err) { body = { detail: text || res.statusText }; }
  if (!res.ok) {
    let d = body && body.detail;
    if (d && typeof d !== "string") d = JSON.stringify(d);
    throw new Error(`Server error ${res.status}: ${d || "request failed"}`);
  }
  return body;
}

function toast(message, kind) {
  const el = document.createElement("div");
  el.className = "toast" + (kind === "bad" ? " bad" : "");
  el.textContent = message;
  $("#toasts").appendChild(el);
  setTimeout(() => el.remove(), kind === "bad" ? 7000 : 4000);
}

function timeAgo(iso) {
  const d = new Date(iso);
  if (isNaN(d)) return "";
  const s = Math.round((Date.now() - d) / 1000);
  for (const [unit, sec] of [["day", 86400], ["hour", 3600], ["minute", 60]]) {
    if (Math.abs(s) >= sec) return rtf.format(-Math.round(s / sec), unit);
  }
  return "just now";
}

/* ---------- stats ---------- */
const reduceMotion = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
function countTo(el, to) {
  const from = el._v ?? 0; el._v = to;
  cancelAnimationFrame(el._raf);
  if (reduceMotion || from === to) { el.textContent = nf.format(to); return; }
  const t0 = performance.now();
  const step = (t) => {
    const p = Math.min(1, (t - t0) / 900);
    el.textContent = nf.format(Math.round(from + (to - from) * (1 - Math.pow(1 - p, 4))));
    if (p < 1) el._raf = requestAnimationFrame(step);
  };
  el._raf = requestAnimationFrame(step);
}

function buildChart() {
  if (chart) { chart.destroy(); chart = null; }
  if (typeof Chart === "undefined" || !fullData) return;
  Chart.defaults.font.family = '"DM Sans", system-ui, sans-serif';
  const { labels, values } = view(), accent = cssVar("--accent"), muted = cssVar("--muted"), line = cssVar("--line"), bar = cType === "bar";
  chart = new Chart($("#chart").getContext("2d"), {
    type: cType,
    plugins: chartPlugins,
    data: { labels, datasets: [{
      label: "Consumption (kWh)", data: values, borderColor: accent, borderWidth: bar ? 0 : 2.5, tension: 0.38, fill: true,
      pointRadius: 0, pointHoverRadius: 6, pointHoverBackgroundColor: cssVar("--paper"), pointHoverBorderColor: accent, pointHoverBorderWidth: 2,
      borderRadius: 7, borderSkipped: false, hoverBackgroundColor: accent,
      backgroundColor: (ctx) => {
        const a = ctx.chart.chartArea;
        if (bar || !a) return rgba(accent, bar ? 0.72 : 0.2);
        const g = ctx.chart.ctx.createLinearGradient(0, a.top, 0, a.bottom);
        g.addColorStop(0, rgba(accent, 0.38)); g.addColorStop(1, rgba(accent, 0));
        return g;
      }
    }] },
    options: {
      responsive: true, maintainAspectRatio: false, layout: { padding: { top: 20, right: 6 } },
      animation: {
        duration: reduceMotion ? 0 : 1300, easing: "easeOutQuart",
        onProgress(c) { if (!c.chart._done) c.chart._p = c.currentStep / c.numSteps; },
        onComplete(c) { c.chart._done = true; c.chart._p = 1; }
      },
      interaction: { mode: "index", intersect: false },
      plugins: {
        legend: { display: false },
        tooltip: {

async function loadIncidents() {
  const list = await api("/api/v1/incidents?limit=10");
  const ul = $("#incidents");
  const key = JSON.stringify(list);
  if (key === incKey) {
    ul.querySelectorAll("time[datetime]").forEach((t) => { t.textContent = timeAgo(t.getAttribute("datetime")); });
    return;
  }
  incKey = key;
  if (!Array.isArray(list) || list.length === 0) {
    renderMix([]);
    ul.innerHTML = '<li class="empty">No incidents yet. Generate demo data or add a CSV to see them here.</li>';
    return;
  }
  renderMix(list);
  ul.innerHTML = list.map((inc, i) => {
    const next = NEXT[inc.status];
    const when = new Date(inc.created_at);
    return `<li class="inc" style="--i:${i}">

  }).join("");
}

"""Time utility functions."""

import datetime as dt


def now_z() -> str:
    """Return the current UTC time in ISO 8601 format with a 'Z' suffix."""
    return dt.datetime.now(dt.UTC).isoformat().replace("+00:00", "Z")


def parse_utc(ts: str) -> dt.datetime:
    """Parse an ISO 8601 timestamp string and return a timezone-aware UTC datetime."""
    # Python 3.11's fromisoformat handles 'Z' natively, but we normalize it for safety.
    clean_ts = ts.replace("Z", "+00:00")
    return dt.datetime.fromisoformat(clean_ts).astimezone(dt.UTC)


def to_z(dt_obj: dt.datetime) -> str:
    """Convert a datetime to an ISO 8601 string with a 'Z' suffix."""
    return dt_obj.astimezone(dt.UTC).isoformat().replace("+00:00", "Z")

"""Canary test: the end-to-end analysis path must detect planted anomalies.

If this test ever fails, the evaluation pipeline has gone silently blind
again (the exact failure mode of the original meter_id bug).

import datetime as dt

from ecofac.domain.models import EnergyReading
from ecofac.persistence.database import get_connection, init_db
from ecofac.persistence.repository import insert_reading
from evaluation.runner import analyze_all, seed_metadata


def test_canary_spikes_are_detected():
    """Plant 3 spikes in flat data; the pipeline must find them."""
    conn = get_connection(":memory:")
    init_db(conn)
    seed_metadata(conn)

    base = dt.datetime(2026, 1, 1, tzinfo=dt.UTC)

    def add(reading_id, hour, value):
        ts = base + dt.timedelta(hours=hour)
        insert_reading(
            conn,
            EnergyReading(
                id=reading_id,
                meter_id="m1-1",
                timestamp_utc=ts.isoformat().replace("+00:00", "Z"),
                value=value,
                unit="kWh",
                source_id="s1",
                batch_id="ib1",
                is_valid=True,
                created_at="2026-01-01T00:00:00Z",
            ),
        )

    for hour in range(48):
        add(f"c{hour}", hour, 10.0)
    for i, hour in enumerate([48, 49, 50]):
        add(f"spike{i}", hour, 100.0)

    detected = analyze_all(conn)

    anomalies = conn.execute("SELECT count(*) AS c FROM anomalies").fetchone()["c"]
    incidents = conn.execute("SELECT count(*) AS c FROM incidents").fetchone()["c"]
    assert detected >= 3, "Pipeline is silently blind to planted spikes"
    assert anomalies >= 3, "Anomaly rows were not persisted"
    assert incidents >= 3, "Eligible anomalies did not produce incidents"
    conn.close()

            conn.execute(

                "VALUES (?, 'm1', ?, ?, 'kWh', 's1', 'ib1', 1, ?)",

            )

def test_transaction_rollback(db_conn):
    """Verify that a failed insert rolls back completely."""
    now = dt.datetime.now(dt.UTC).isoformat()

    db_conn.execute("INSERT INTO organizations (id, name, created_at) VALUES ('o2', 'O2', ?)", (now,))

    try:
        db_conn.execute("BEGIN")
        db_conn.execute("INSERT INTO buildings (id, org_id, name, created_at) VALUES ('b2', 'o2', 'B2', ?)", (now,))
        # Force an error by inserting a duplicate primary key
        db_conn.execute("INSERT INTO buildings (id, org_id, name, created_at) VALUES ('b2', 'o2', 'B2-dupe', ?)", (now,))
        db_conn.execute("COMMIT")
    except sqlite3.IntegrityError:
        db_conn.execute("ROLLBACK")

    # Verify the first insert was rolled back
    cursor = db_conn.execute("SELECT count(*) as c FROM buildings WHERE id='b2'")
    assert cursor.fetchone()["c"] == 0

        "timestamp,building_id,meter_id,energy_value,unit\n"
        "2026-01-01T12:00:00Z,b1,m1,10.5,kWh\n"
        "2026-01-01T12:00:00Z,b1,m1,20.0,kWh\n"
    )
    ingest_csv(db_conn, csv_data, "s1", "ib1")
    row = db_conn.execute(
        "SELECT meter_id, reading_timestamp_utc FROM data_quality_issues "
        "WHERE issue_type = 'duplicate'"
    ).fetchone()
    assert row["meter_id"] == "m1"
    assert row["reading_timestamp_utc"] == "2026-01-01T12:00:00Z"
