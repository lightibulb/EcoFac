7. Known limitations.

· Mocked DB in tests: The tests use an in-memory SQLite DB by overriding the get_db dependency, which is standard FastAPI practice.
· File size limit: The 5MB check occurs after FastAPI/Starlette buffers the file in memory via await file.read(). For a true production system, you'd want a streaming check to prevent memory exhaustion before reading. This is documented as a local demo limitation.

8. Any unresolved risks.

· B008 rule: As expected, FastAPI's Depends() triggers Ruff's B008. We ignored it globally, which is the standard workaround.
· SQLite Lock: If the API runs with multiple workers (uvicorn --workers 4), SQLite may throw "database is locked" errors during concurrent writes. We are running single-process for this demo.
