7. Known limitations.

· The SQL window size for historical data (LIMIT ?) operates on count, not time span. If a meter has missing hours, window_size=24 might look back 3 days instead of 24 hours.
· Comparable period detection is deferred to Part 7 to avoid massive query complexity in a single stage.

8. Any unresolved risks.

· Epsilon substitution for Zero MAD: When MAD is 0 (constant data), using 1e-6 means any deviation triggers an anomaly. This is mathematically sound for deterministic energy data, but could cause alert fatigue if the meter naturally fluctuates by 0.01.
· Percentage deviation division by zero: Handled by returning None if expected <= 0.
