7. Known limitations.

· We are using raw SQL instead of an ORM like SQLAlchemy. While this guarantees zero dependencies and explicit control, future schema changes will require writing migration scripts manually (or dropping/recreating the dev database).
· SQLite operates at the database level for locking. Highly concurrent writes might see database is locked errors, but this is explicitly out of scope for initial deployment.

8. Any unresolved risks.

· CI Runtime: The integration tests use tmp_path to verify persistence. Python's tempfile behavior is generally robust, but if the GitHub Actions runner blocks file writes to /tmp, the test could fail.
